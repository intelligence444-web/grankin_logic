# grankin_logic

Поисковые товарные кампании Яндекс Директа (ЕПК + фид) для страниц estate-start.ru по логике урока Антона Гранкина.
Владелец: маркетолог по недвижимости. Язык общения и документов — русский.

## Структура

- `data/feed.json` — единственный источник данных фида (объекты, карточки F1–F3).
- `scripts/build_feed.py` — собирает `feeds/estate_start_feed.yml` и проверяет по правилам Директа. Фид руками не правим — правим `data/feed.json` и пересобираем.
- `feeds/minus_words.txt` — минус-фразы против запросов про отдых и бронь.
- `images/<объект>/` — рендеры для фида (JPG, от 450 px). В фиде они превращаются в прямые ссылки `raw.githubusercontent.com/.../main/images/...` — поэтому картинки работают только после пуша в `main`. Не переименовывать и не удалять файлы, на которые ссылается загруженный фид.
- `docs/direct_feed_rules.md` — правила Директа для фидов (по справке). Сверяться перед каждой правкой.
- `docs/method.md` — конспект логики Гранкина.
- `docs/launch.md` — план запуска и открытые вопросы.

## Правила проекта

- Сайт estate-start.ru (Flexbe) не меняем и ничего туда не загружаем, пока пользователь явно не попросит. Правки сайта — только черновиком с превью, публикация — по команде.
- Не пишем про доход, прибыль, окупаемость и гарантии — ни в фиде, ни в объявлениях.
- Факты берём только со страниц сайта или от пользователя. Цены, площади, типы номеров не выдумываем.
- Продаём номера и апартаменты в собственность, а не отдых: в начале `name` — «в собственность» или «инвестиционный»; категории — «… в собственность».
- В `name` и `description` нет рекламного текста и слов о продаже; условия оплаты — только в `sales_notes`.
- ID товаров — числовые и не меняются (на них завязаны фильтры в объявлениях): 1xx — Ризалта, 2xx — Вера, 3xx — Агой; последняя цифра — вариант F1/F2/F3.
- Фильтр по фиду — на уровне товарного объявления; каждый объект — отдельная кампания.
- Картинки: до 5 на карточку, первая — главная (её Директ берёт, когда помещается одна). У карточки может быть свой набор `pictures` — это часть креатива варианта. Рендеры с надписями и логотипами (например, вывеска PALAZZO DE AGOY) в фид не ставим.
- Справка Директа: https://yandex.ru/support/direct/ru/ — если правило под вопросом, читать справку, а не полагаться на память.

## Проверка

```bash
python3 scripts/build_feed.py
```

Скрипт падает с ошибкой, если нарушены лимиты (name ≤ 56, description + sales_notes ≤ 81, property name ≤ 26, ≤ 10 характеристик, ≤ 5 картинок), ID не числовой или повторяется, или встречены запрещённые слова.
