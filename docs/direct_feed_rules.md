# Правила Яндекс Директа для фидов и товарных объявлений

Сверено со справкой Директа 24.11.2026. Перед любой правкой фида проверяем его по этому списку.
Если справка изменилась, обновляем этот файл и лимиты в `scripts/build_feed.py`.

| Что | Правило |
| --- | --- |
| Где фильтр | В товарном объявлении ЕПК (блок «Товары → Фильтр»), не в группе. В группе до 2 активных товарных объявлений. Условия соединяются через «И». Директ в реальном времени показывает, сколько товаров попало под фильтр |
| ID товара | Если по фиду настраиваются фильтры — только числовые ID. Уникальные, до 100 знаков |
| Категория | Одна на товар, `categoryId` — целое положительное число. Фильтр по пустой родительской категории (с вложенными через `parentId`) не работает — делаем категории плоскими |
| `name` | Формула ЧТО + КТО + МОДЕЛЬ + характеристики. Должно совпадать с тем, что на странице перехода. Без рекламного текста, капса и спецсимволов |
| `description` | Характеристики. Нельзя: рекламный текст, ссылки, сведения о продаже, конкуренты |
| `sales_notes` | Условия оплаты, акции: сюда «рассрочка 0%», «взнос от 20%» |
| Длина в объявлении | Заголовок до 56 символов, текст до 81. В ручном режиме до 5 элементов фида склеиваются по порядку, лишнее обрезается. Для YML доступны: `name`, `typePrefix`, `model`, `vendor`, `description`, `sales_notes` |
| `picture` | До 5 штук, от 450 px по каждой стороне, JPG/PNG/WebP/GIF, до 10 МБ. Только прямая ссылка на файл (Яндекс Диск не подходит). Обязательна для товарной галереи. Чтобы обновить картинку — менять ссылку |
| `price` | Обязательна для товарной галереи, должна совпадать с сайтом. `from="true"` (цена «от») в справке по товарному YML не описан — проверить при загрузке |
| `property name` | До 10 характеристик, название до 26 символов. Показываются только в товарной галерее |
| `custom_label_0…4` | До 175 символов. Только для фильтров в ЕПК, на текст объявления не влияют |
| Замена фида | Директ пытается сохранить фильтры; если под фильтр не попадает ни одного товара — фильтр сбрасывается. ID карточек не меняем |
| Автотаргетинг на поиске | Подбирает запросы по заголовку (без доп. заголовка), тексту и странице перехода. Категории: целевые, узкие, широкие, альтернативные, сопутствующие + упоминание бренда (свой / конкуренты / без бренда). Изменения применяются до суток. В ЕПК есть «Примеры запросов» по категориям (можно выгрузить XLSX) — смотрим до запуска. Минус-фразы работают и для автотаргетинга |
| Товарная галерея | Для товаров; на поиске показ по ключам или автотаргетингу. Для недвижимости показ не гарантирован |

## Закон о рекламе (наши ограничения)

- Не обещаем доходность: слова «доход», «прибыль», «окупаемость», «гарантия» в фид не пишем.
- Реклама долевого строительства: на странице должна быть ссылка на проектную декларацию (наш.дом.рф).
- Факты в фиде должны совпадать с сайтом. Если на сайте противоречие (банк, срок рассрочки) — в фид это не пишем.
