## Настройки кампании-донора

- Тип: Единая перфоманс-кампания. Места показа: только поиск (поиск, товарная галерея, динамические места).
- Стратегия: пакетная, оплата за конверсии. Реальная цель — заявка с формы; вторая цель — квал из CRM. Недельный бюджет 10–15 тыс. ₽.
- Группа: автотаргетинг — только «целевые» и «узкие»; «широкие», «альтернативные», «сопутствующие» выключены. До запуска выгрузить «Примеры запросов» и проверить, нет ли запросов про отдых.
- Минус-фразы: `feeds/minus_words.txt` на уровне кампании.
- Товарное объявление: источник — фид с компьютера (`feeds/estate_start_feed.yml`); фильтр — ID товара (Директ должен показать «1 товар»); элементы фида — ручные: заголовок = `name`, текст = `description`, затем `sales_notes`.
- Параметры URL: `utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content=<ID товара>&utm_term={keyword}`.
- Корректировки: возраст до 18 — −100%. Саджест и эксклюзив — не больше +100…+200% на старте.
