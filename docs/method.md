# Логика запуска (по уроку Антона Гранкина)

Краткий конспект урока о поисковых товарных кампаниях. Полную расшифровку в репозиторий не кладём.

## Идея

- Цель — охват, но только на поиске: с поиска идут качественные заявки, с РСЯ — спам и дубли.
- Тип кампании — ЕПК (не Мастер кампаний: он крутится и на РСЯ). Площадки — только поиск, все три галки: поиск, товарная галерея, динамические места.
- Объявления строятся из фида. Фид — это креатив; всё остальное — технические параметры.
- Таргетинг — автотаргетинг (можно с ключами).

## Переменные для масштабирования

| Переменная | Что это |
| --- | --- |
| A | Тип кампании: ЕПК или Мастер |
| B | Таргетинг: автотаргетинг целиком / частично / ключи / ключи + автотаргетинг |
| C | Домены и посадочные страницы |
| D | Цели (пакетные стратегии) |
| E | Аккаунты Директа |
| F | Фиды (креативы) |

В каждой копии кампании меняем одну переменную — иначе непонятно, что дало результат.

## Порядок

1. Рабочий документ: URL посадок, цели Метрики, данные для фида, UTM.
2. Одна кампания-донор: один домен, один аккаунт, один фид. Сутки смотрим, что прошла модерация и идут показы.
3. Масштабирование копированием донора лесенкой: пакеты целей → страницы → фиды → аккаунты.

## Стратегии и «газ»

- Пакетные стратегии с оплатой за конверсии. Обязательно реальная цель, за которую списываются деньги (заявка), плюс более дорогая вторая цель (квал, встреча из CRM), достигаемая несколько раз в неделю.
- Недельный бюджет так, чтобы набиралось 10–12 конверсий.
- Корректировки на рекламу в саджесте и эксклюзивное размещение — осторожно: они умножают цену конверсии.
- Понижающие корректировки по аудиториям, которые не дают квалов.
- Если кампании за конверсии не тратят — страховочная кампания за клики.

## Оценка

Главный KPI — цена квалифицированного лида и его платёжеспособность. Цена лида с НДС (×1,22), с учётом кликового расхода и купонов. Ориентир: с поиска квалов 10–30% от заявок.

## Почему у Гранкина 90–160 фидов и нужно ли множить домены

### Откуда столько фидов

Это произведение переменных, а не отдельная техника:

- URL страницы записан в фиде («Если я хочу на другой URL, то я меняю фид») — новая страница = новый фид.
- Варианты креатива (разные заголовки, фото, цены) — ещё множитель.
- Логины: «создай товарную кампанию на четырёх логинах под один URL… умножаем на четыре». Фиды хранятся в кабинете, поэтому на каждый логин загружаются заново.
- Копии под пакеты целей новых фидов не требуют, но при заливке через ИИ проще грузить фид в каждую кампанию — поэтому фидов примерно столько же, сколько кампаний.

Пример: 4 страницы × 3 креатива × 4 логина = 48 фидов; с пакетами целей — 90–160 кампаний. Сам автор называет это гиперсегментацией и хочет прийти к одной кампании, которая тащит объём.

### Домены

В уроке переменная C — «домены, страницы: можно один домен, а можно 10». В товарной галерее он показывает «мой сайт, мой сайт, мой сайт, конкурент, мой сайт» — по видео не понять, разные это домены или несколько карточек одного сайта.

Правила Директа:

- [Сходные сайты](https://yandex.ru/support/direct/ru/troubleshooting/clones): из нескольких объявлений, ведущих на один ресурс или на сходные сайты, показывается только одно. Сходные — если идентичные товары предлагает один поставщик или значительная часть предложений совпадает в одном регионе. Правило про сайты, а не про кабинеты: дополнительные логины на тот же сайт его не обходят. Конкуренты могут пожаловаться через форму.
- [Товарная галерея](https://yandex.ru/support/direct/ru/product-gallery/about): в неё может попасть больше 5 карточек одного бизнеса (разные товары). Для нескольких мест в галерее домены не нужны — нужны несколько карточек.

### Решение для estate-start.ru

1. Домены не множим. Ризалта, Вера и Агой — разные товары в разных регионах, по запросам не пересекаются; одного estate-start.ru достаточно.
2. Масштаб — через пакеты целей (D) и варианты фида (F): они не упираются в правило сходных сайтов.
3. Второй домен — только как тест посадочной для одного объекта (например, квиз вместо страницы): одна кампания, сравниваем цену квала. Если Директ признает сайты сходными, покажется одно объявление из двух — тест будет конкурировать с основной кампанией, это учитываем.
