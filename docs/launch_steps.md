# Запуск донора по шагам: ЕПК «Ризалта», фид, только поиск

Сверено со справкой Директа ([товарное объявление в ЕПК](https://yandex.ru/support/direct/ru/unified-performance-campaign/create-product), [стратегии](https://yandex.ru/support/direct/ru/strategies/average-cpa)). Названия кнопок в интерфейсе Директ иногда меняет — если пункт называется иначе, ищем по смыслу.

## 0. Перед стартом

- [ ] На счёте Директа есть деньги — без них товарные объявления не генерируются (справка).
- [ ] Счётчик Метрики 108372294 доступен с логина Директа.
- [ ] Файл фида: [`feeds/estate_start_feed.yml`](../feeds/estate_start_feed.yml) — скачать из репозитория (кнопка Download raw file).
- [ ] Минус-фразы: [`feeds/minus_words.txt`](../feeds/minus_words.txt).

## 1. Загрузить фид

1. Директ → **Фиды** → **Добавить фид**.
2. Название: `estate_start_feed`. Тип: **Товары** (YML). Источник: **файл с компьютера** → `estate_start_feed.yml`.
3. Дождаться обработки (статус «Обработан»). Проверить: **9 товаров**, ошибок нет.
4. Если ошибка — прислать скриншот. Самое вероятное место — атрибут `price from="true"`: его уберу и пересоберу фид.

Почему с компьютера, а не по ссылке: фид будет меняться по нашей команде, а не автоматически. По ссылке (raw GitHub) можно перейти позже.

## 2. Создать кампанию

1. **Создать** → **Единая перфоманс-кампания** (не Мастер кампаний).
2. Ссылка на сайт: `https://estate-start.ru/rizalta/`.
3. Название кампании: `ЕПК | Поиск | Фид | Ризалта | F1 | 101` — по названию видно все переменные (A, C, F). Копии называем так же, меняя одну часть.
4. **Цели и стратегия:**
   - Счётчик: 108372294.
   - Стратегия: **Максимум конверсий**, оплата **за конверсии**.
   - Цели (пакет):
     - «Спасибо (матомба)» (670459659) — **100 ₽**;
     - «CRM: Заказ создан» (545044721, квал-лид) — **1000 ₽**.
   - Шаги квиза и «Заказ оплачен» в стратегию не добавлять.
   - Недельный бюджет: **10 000 ₽** (поднимем до 15 000, если упрёмся в бюджет).
5. **Места показа: только поиск.** Оставить три галки:
   - поиск,
   - товарная галерея,
   - динамические места.
   Рекламную сеть (РСЯ) — выключить.
6. **Регион:** Россия (покупатели-инвесторы из разных городов). Сузим по отчёту «География» после первой недели.
7. **Минус-фразы кампании:** вставить весь `minus_words.txt`.
8. **Корректировки (уровень кампании):**
   - реклама в саджесте — **+100%**;
   - эксклюзивное размещение — **+100%**;
   - возраст до 18 — **−100%**.
   Больше на старте не ставим: корректировка умножает цену конверсии (+100% → заявка 200 ₽, квал 2000 ₽).
9. **Счётчики / разметка:** включить автоматическую разметку ссылок (yclid).

## 3. Группа объявлений

1. Название группы: `Ризалта | автотаргетинг`.
2. **Таргетинг: автотаргетинг.** Категории запросов:
   - ✅ целевые;
   - ✅ узкие;
   - ❌ широкие, альтернативные, сопутствующие.
   Упоминание бренда: оставить по умолчанию (запросы с брендом и без).
3. Ключевые фразы не добавляем.
4. Перед сохранением открыть **«Примеры запросов»** автотаргетинга. Если там отдых, бронь, туры, санаторий — дописать слова в минус-фразы кампании.

## 4. Товарное объявление (здесь фильтр)

1. В группе → **Товарное объявление**.
2. Источник: **ранее загруженный фид** `estate_start_feed`.
3. Раздел **Товары → Фильтр:** **ID товара = 101**. Директ должен показать **«1 товар»**. Если показывает 9 — фильтр не применился.
4. Элементы фида: **ручные**:
   - Заголовок: `name`;
   - Текст: `description`, затем `sales_notes`.
5. Каталоги: не используем (выключить, если включены).
6. **Параметры URL:**
   ```
   utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content=101&utm_term={keyword}
   ```
7. **Уточнения** (до 4, без рекламы дохода): «ДДУ по 214-ФЗ», «Ремонт и мебель», «Рассрочка 0%», «Белокуриха, Алтай».
8. **Быстрые ссылки:** если на странице есть якоря (планировки, условия, контакты) — добавить; если нет — пропустить. Сайт не меняем.
9. Контакты / визитка: телефон и адрес — только реальные.
10. **Отправить на модерацию.**

## 5. После модерации (обычно несколько часов)

- [ ] Статус «Допущена модератором». Если отклонение — прислать причину.
- [ ] Через 2–4 часа после старта в статистике есть показы.
- [ ] Через сутки — **копии на Веру и Агой**: «Копировать кампанию», в копии поменять:
  - ссылку на сайт (`/vera/` или `/agoy/`),
  - название (`… | Вера | F1 | 201` / `… | Агой | F1 | 301`),
  - фильтр в товарном объявлении (ID = 201 / 301),
  - `utm_content` (201 / 301),
  - уточнения (под объект).
  Всё остальное — без изменений.

## 6. Первая неделя

- Каждый день: отчёт **«Поисковые запросы»** → всё про отдых, бронь, аренду → в минус-фразы.
- Брендовые запросы («Ризалта», «Вера», «Палаццо»): если по ним ищут отдых — переключить фильтр донора на F2 (ID 102 / 202 / 302, без бренда).
- Ничего не менять 7 дней, кроме минус-фраз: изменения стратегии и корректировок перезапускают обучение.
- Через 7 дней — смотрим заявки, квал-лиды, спам из CRM; решаем по корректировкам (+300%?) и следующей «ступеньке».
